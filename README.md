# Irogasane

A Mac app for building colour palettes.

**[Download the latest version](https://github.com/ozgurdesign/irogasane/releases/latest)** · [irogasane.com](https://irogasane.com)

## What it does

- **Scale** turns one colour into shades, tints, tones and hue steps.
- **Pair** builds harmonies around it, from complementary to analogous.
- **Mix** blends between colours on a board of 72 cells.
- **Theme** makes a full theme in twelve steps per colour.
- **Contrast** checks any pair against WCAG 2 and APCA, and adjusts a failing pair by lightness only.
- **Learn** has short lessons that use your own colour.

Palettes hold up to 12 colours, save as you go, and export as ASE, SVG or CSS.

## Download

Each release has one disk image, `Irogasane-<version>.dmg`, for macOS 15.5 Sequoia and later.

The "Source code" links GitHub adds to every release only contain this README and the licence. The app is the `.dmg`.

## First launch

Irogasane is not notarized by Apple yet, so macOS asks before opening it the first time.

1. Open the disk image and drag Irogasane to Applications.
2. Open Irogasane once. macOS says it can't check the app.
3. Go to System Settings › Privacy & Security and click Open Anyway.

You only need to do this once.

## Privacy

The app has no network access. Your palettes stay on your Mac, and nothing is collected.
